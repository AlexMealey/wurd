      Executive Summary

      Welcome to Wurd, the privacy-first word processing environment engineered for rapid drafting, cross-format document interoperability, and end-to-end security.

      Core Architecture & Compatibility

      This editor provides seamless fidelity across .docx, .odt, and legacy .doc files while running client-side with zero unauthorized data telemetry.

      • Client-side zero-knowledge document encryption
      • Instant bi-directional WYSIWYG & HTML Source rendering
      • Automatic structural outline extraction

      Security Posture

      All stored artifacts are secured using client-side cryptographic primitives prior to serialization.
